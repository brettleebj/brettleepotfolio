# Jonathan Brettlee - Personal Portfolio

A modern, responsive, and SEO-friendly personal portfolio website for Jonathan Brettlee, a Full-Stack Web Developer Intern and Founder of Lee Sage.

## Features

- **Responsive Design**: Mobile-first approach with clean, modern UI
- **Dark/Light Mode Toggle**: User preference saved in localStorage
- **Smooth Animations**: Subtle animations and transitions for better UX
- **SEO Optimized**: Proper meta tags, semantic HTML, and structured data
- **Accessibility**: Keyboard navigation, screen reader friendly
- **Fast Loading**: Optimized CSS and JavaScript

## Sections

1. **Hero**: Introduction with call-to-action buttons
2. **About**: Personal information and background
3. **Skills**: Technical skills categorized by area
4. **Projects**: Showcase of key projects
5. **Experience**: Professional experience and internships
6. **Certifications**: Educational achievements
7. **Contact**: Contact form and information

## File Structure

```
portfolio/
├── index.html          # Main HTML file
├── styles.css          # CSS styles
├── script.js           # JavaScript functionality
```

## Customization

### Images
Replace the placeholder images with your actual photos:
- `profile.jpg`: Your professional headshot
- `about.jpg`: A relevant image for the about section
- `leesage-project.jpg`: Screenshot of your Lee Sage project

### Content
Update the content in `index.html` to reflect your latest information:
- Personal details
- Skills
- Projects
- Experience
- Certifications

### Styling
Modify `styles.css` to change colors, fonts, or layout:
- Update CSS variables in `:root` for theme colors
- Adjust responsive breakpoints
- Customize animations and transitions

### Functionality
Enhance `script.js` for additional features:
- Add form submission handling
- Integrate analytics
- Add more interactive elements

## SEO Optimization

The portfolio includes:
- Proper meta tags (title, description, keywords)
- Semantic HTML structure
- Alt text for images
- Structured data (consider adding JSON-LD)
- Fast loading times
- Mobile-friendly design

## Deployment

1. Upload all files to your web hosting service
2. Ensure the domain points to the `index.html` file
3. Test all links and functionality
4. Submit to search engines for indexing
